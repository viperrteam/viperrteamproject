# viperrteamproject
# AI-система для персонализации образовательных траекторий

Веб-сервис для подбора учебных материалов на основе интересов пользователя с использованием рекомендательных алгоритмов.

## 📋 О проекте

Данный проект разрабатывается в рамках образовательного кейса для студентов 2-го семестра. Цель — создание MVP веб-сервиса, который помогает пользователям находить релевантные учебные материалы (курсы, статьи, видео) на основе их интересов и профиля.

### 🎯 Основные возможности

- Регистрация и аутентификация пользователей
- Заполнение профиля с указанием интересов
- Просмотр каталога учебных материалов
- Персональные рекомендации на основе совпадения тегов
- Администрирование базы материалов

### 🛠️ Технологический стек

| Компонент | Технология |
|-----------|-----------|
| Backend | Flask 3.0+ |
| ORM | Flask-SQLAlchemy 3.1+ |
| База данных | SQLite |
| Аутентификация | Flask-Login 0.6+ |
| Хэширование | Werkzeug 3.0+ |
| Фронтенд | HTML/CSS/ |

## 🗄️ Структура базы данных

### Схема (4 основные таблицы + 2 связующие)

```sql
users           — пользователи (user_id, username, email, password_hash, created_at, last_login)
tags            — теги (tag_id, tag_name, material_id)
materials       — учебные материалы (material_id, user_id, title, content, type)

user_interests  — связь пользователь ↔ теги (user_id, tag_id)
material_tags   — связь материал ↔ теги (material_tag_id, material_id, tag_id)
```

## 📝 Использование
### Регистрация и вход 
 - Перейдите на http://localhost:5000/register

 - Заполните форму (username, email, пароль)

 - После регистрации произойдёт автоматический вход

### Настройка интересов
 - Перейдите в Профиль (после входа)

 - Выберите теги, которые соответствуют вашим интересам

 - Нажмите "Сохранить интересы"

 - Поиск курсов
 - Используйте строку поиска по названию

 - Фильтруйте курсы по тегам

 - Навигация по страницам (пагинация)

### Выход из системы
 - Нажмите Выйти в меню навигации
